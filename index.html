Socials Dashboard

A private analytics dashboard for Lydia's accounts

Built and operated by Peter Causey. It connects to Lydia's own Instagram and TikTok accounts — and the brand accounts she manages — through each platform's official login, then shows day-over-day views, likes, follows, and engagement rate in one place instead of scattered across each app's native analytics.

What it does

  • Pulls post and account metrics on a recurring schedule via the Instagram Graph API and the TikTok Display API — never by scraping.
  • Normalizes raw totals into engagement/save/share rates, since a bigger number isn't automatically better content.
  • Surfaces top and bottom performers each week so Lydia knows which posts are worth a closer look.

Who can use it

Only Lydia and the small set of brand accounts she manages, each connected by that account's own owner through the platform's official OAuth flow. It isn't a public product.
